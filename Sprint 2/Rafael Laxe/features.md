Requisitos Funcionais e Não Funcionais + Casos de Uso

Requisitos Funcionais

1 - O sistema deve permitir o cadastro e login do restaurante.

02 - O restaurante deve poder criar um cardápio digital.

3 - O restaurante deve poder cadastrar informações como nome, descrição e imagem do estabelecimento.

4 - O restaurante deve poder criar, editar e excluir categorias do cardápio.

5 - O restaurante deve poder cadastrar produtos com nome, descrição, preço e foto.

6 - O restaurante deve poder editar ou excluir produtos cadastrados.

7 - O restaurante deve poder marcar produtos como disponíveis ou indisponíveis.

8 - O sistema deve permitir a visualização prévia do cardápio.

9 - O sistema deve gerar um QR Code específico para o cardápio do restaurante.

10 - O cliente deve conseguir acessar o cardápio ao escanear o QR Code.

11 - O restaurante deve poder atualizar o cardápio sem precisar gerar um novo QR Code.

Requisitos Não Funcionais

1 - O sistema deve possuir uma interface simples e fácil de utilizar.

2 - O cardápio deve funcionar corretamente em celulares, tablets e computadores.

3 - As páginas do cardápio devem carregar rapidamente.

4 - O sistema deve armazenar os dados dos restaurantes de forma segura.

5 - Apenas usuários autorizados devem poder editar o cardápio de um restaurante.

6 - O QR Code deve permanecer válido mesmo após alterações no cardápio.

7 - O sistema deve funcionar nos principais navegadores atuais.

Casos de Uso

1 - Criar cardápio

Ator: Restaurante

O restaurante acessa sua conta, cria um novo cardápio e adiciona as informações básicas do estabelecimento.

2 - Cadastrar produto

Ator: Restaurante

O restaurante seleciona uma categoria e adiciona um produto, informando nome, descrição, preço e foto.

3 - Editar cardápio

Ator: Restaurante

O restaurante altera produtos, preços, categorias ou disponibilidade dos itens já cadastrados.

4 - Gerar QR Code

Ator: Restaurante

Após criar o cardápio, o restaurante solicita ao sistema a geração de um QR Code para disponibilizar aos clientes.

5 - Visualizar cardápio

Ator: Cliente

O cliente escaneia o QR Code e o sistema apresenta o cardápio digital do restaurante.

6 - Marcar produto como indisponível

Ator: Restaurante

O restaurante seleciona um produto e altera seu status para indisponível, fazendo com que essa informação seja atualizada no cardápio exibido aos clientes.
